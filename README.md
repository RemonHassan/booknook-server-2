# BookNook Backend API

A robust Node.js and Express backend API for the **BookNook** library management platform, powered by MongoDB and secured with JWT verification using Jose.

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Official Driver)
- **Authentication & Security:** `jose` (JWT verification with remote JWKS), `cors`
- **Configuration:** `dotenv`

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- MongoDB Database (Atlas or local instance)

### 1. Installation

Clone the repository and install the dependencies:

```bash
npm install
```
